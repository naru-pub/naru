MCP(Model Context Protocol)는 AI 앱이 다른 서비스를 쓸 수 있게 하는 연결
방법이에요. MCP를 지원하는 앱을 나루에 연결하면, 그 앱에게 말로 부탁해서 내
홈페이지의 파일을 읽고, 만들고, 고칠 수 있어요. 서포터 기능이에요.

## 01 · 연결하기 {#connect}

1. 쓰는 앱에 MCP 서버로 아래 주소를 추가하세요. 추가하는 방법은 앱마다 달라요.
   [Claude](https://support.claude.com/ko/articles/11175166),
   [Claude Code](https://code.claude.com/docs/ko/mcp),
   [ChatGPT](https://help.openai.com/ko-kr/articles/12584461-connecting-custom-mcp-servers-in-chatgpt)의
   안내를 보세요.

   ```
   {{mcp_url}}
   ```

2. 앱이 나루 로그인 화면을 열어요. 나루 계정으로 로그인하세요.
3. 연결할 앱의 이름과 돌아갈 주소를 확인하고, 허용할 일을 고른 뒤 ‘연결’을
   누르세요. 읽기만 허용하면 앱은 파일을 바꾸지 못해요. 데이터베이스 문서는 따로
   골라야 허용돼요.

## 02 · 이렇게 부탁해 보세요 {#ask}

연결한 뒤에는 앱과 대화하듯 부탁하면 돼요. ‘나루에서’라고 말해 주면
앱이 나루 연결을 써요. 어느 파일인지, 무엇을 바꾸고 싶은지 구체적으로
말할수록 좋아요.

> 나루에서 index.html을 읽고, 자기소개를 더 따뜻한 말투로 고쳐 줘.

> 나루에서 diary 폴더에 오늘 날짜로 일기 페이지를 하나 만들고, index.html에 링크를 달아 줘.

> 나루에서 내 홈페이지 파일들을 보고 깨진 링크가 있는지 찾아 줘.

> 나루에서 style.css의 색을 가을 느낌으로 바꿔 줘. 바꾸기 전에 무엇을 바꿀지 먼저 알려 줘.

> 나루에서 방문자가 인사를 남길 수 있는 방명록을 만들어 줘.

> 나루에서 글 목록과 글 페이지가 있는 블로그를 만들고, 첫 글로 자기소개를 올려 줘.

앱이 파일을 저장하면 그 즉시 홈페이지에 공개돼요. 중요한 페이지는 바꾸기 전에
무엇을 바꿀지 먼저 보여 달라고 하세요. 앱이 고친 파일은
[파일 편집기](/files)에서도 바로 보이고, 거기서 다시 고칠 수 있어요.

## 03 · 앱이 할 수 있는 일 {#tools}

연결된 앱은 내 사이트 하나의 파일과 데이터베이스 컬렉션을, 허용했다면
데이터베이스 문서도 다뤄요. 계정 설정, 결제, 커스텀 도메인은 다룰 수 없어요.
앱은 [웹 SDK 1.0.0](/docs/sdk/1.0.0) 사용법을 읽고 방명록이나 블로그처럼
데이터를 쓰는 페이지를 만들 수 있어요. 새 컬렉션은 바로 만들어지지만, 이미 있는
컬렉션의 공개 범위를 넓히는 변경은 [데이터베이스](/database)에서 내가 승인해야
반영돼요. 데이터베이스 문서에는 방문자가 쓴 글이 있어 앱이 그 글에 휘둘릴 수
있으니, 문서는 필요할 때만 허용하세요.

| 도구                    | 권한                | 하는 일                                             |
| ----------------------- | ------------------- | --------------------------------------------------- |
| `get_site`              | 읽기                | 사이트 주소, 제목, 마지막 수정 시각, 서포터 기간    |
| `list_files`            | 읽기                | 폴더 아래 파일과 크기, 수정 시각                    |
| `read_file`             | 읽기                | 텍스트 파일의 내용, 이미지                          |
| `write_file`            | 수정                | 파일을 만들거나 통째로 바꾸고 바로 공개             |
| `move_file`             | 수정                | 파일 옮기기, 이름 바꾸기                            |
| `delete_file`           | 수정                | 파일 지우기 (되돌릴 수 없음)                        |
| `get_sdk_reference`     | 누구나              | 웹 SDK 1.0.0 사용법과 레퍼런스                      |
| `list_collections`      | 읽기                | 컬렉션과 읽기·쓰기 공개 범위                        |
| `configure_collections` | 수정                | 컬렉션 만들기 (공개 범위를 넓히는 변경은 내가 승인) |
| `list_documents`        | 데이터베이스        | 컬렉션의 문서 목록, 필터와 정렬                     |
| `get_document`          | 데이터베이스        | 문서 하나                                           |
| `set_document`          | 데이터베이스 + 수정 | 문서를 만들거나 통째로 바꾸고 바로 반영             |
| `delete_document`       | 데이터베이스 + 수정 | 문서 지우기 (되돌릴 수 없음)                        |

`_naru/collections.json`처럼 `_naru/` 폴더에 저장한 파일도 파일 편집기에서
저장할 때와 똑같이 적용돼요.

## 04 · 한도 {#limits}

- 파일 하나는 10 MB까지, [파일 편집기](/help/files#limits)와 같은 형식만 올릴
  수 있어요.
- `read_file`은 1 MB까지의 텍스트와 이미지를 돌려줘요. 그보다 큰 파일은 주소만
  알려 줘요.
- `index.html`은 지우거나 옮길 수 없어요.
- 연결 하나는 분당 120번까지 요청할 수 있어요.

## 05 · 연결 끊기 {#disconnect}

[계정](/account)의 ‘MCP 연결’에서 앱마다 ‘연결 끊기’를 누르면 그 앱은 바로
사이트를 읽거나 고칠 수 없게 돼요. 30일 동안 쓰지 않은 연결은 다시 로그인해야 해요. 서포터
기간이 끝나면 연결은 남지만, 다시 서포터가 될 때까지 앱은 사이트를 읽거나 고칠 수 없어요.
