템플릿은 다른 사람이 만들어 나눈 사이트예요. 내 사이트에 적용하면 그대로 내
홈페이지가 되고, 만든 사람이 새 버전을 내면 내가 고른 때에 업데이트할 수 있어요.

## 01 · 적용하기 {#apply}

[템플릿](/templates)에서 마음에 드는 것을 골라 ‘내 사이트에 적용’을 누르세요.
어디에 적용할지 물어봐요.

- **새 폴더에**: 기존 사이트는 그대로 두고 폴더 하나에 넣어요. 먼저 시험해 보기
  좋아요.
- **사이트 전체(/)**: 홈페이지가 이 템플릿으로 바뀌어요. 겹치는 파일만 덮어쓰고,
  나머지 파일은 건드리지 않아요.

‘바뀌는 파일 보기’에서 무엇이 바뀌는지 확인한 뒤 적용하세요. 덮어쓰는 파일은
`/.backup/`에 보관해요.

사이트 코드(`_naru/`)가 있는 템플릿은 사이트 전체에만 적용할 수 있고, 서포터 플랜의
데이터베이스 기능이 필요해요. 사이트 코드는 사이트에 하나만 둘 수 있어서, 이미
설치한 다른 템플릿이 있으면 그 템플릿과 바꿀지 물어봐요.

## 02 · 내 것으로 고치기 {#customize}

템플릿의 파일을 직접 고치지 말고, 템플릿이 쓰는 설정이나 `/{{owner}}/` 폴더에 바꿀
것을 두세요. 그래야 업데이트할 때 다시 옮길 일이 없어요.

- 사이트 이름, 색, 메뉴처럼 템플릿의 운영 화면에서 정하는 것은 업데이트와 상관없이
  남아요.
- `/{{owner}}/` 폴더의 파일은 설치도, 업데이트도, 연결 끊기도 건드리지 않아요. 이
  폴더의 파일을 불러와 주는 템플릿이라면 여기에 내 스타일과 스크립트를 두세요.

어떤 설정이 있고 `/{{owner}}/`의 어떤 파일을 불러오는지는 템플릿마다 달라요. 템플릿의
글을 보세요.

## 03 · 업데이트하기 {#updates}

새 버전이 나오면 알림이 오고, 내비게이션의 템플릿 메뉴에 숫자가 표시돼요.
저절로 바뀌지는 않아요. [설치한 템플릿](/templates/installed)에서 ‘바뀌는 파일
보기’로 확인한 뒤 업데이트하세요. 알림을 받고 싶지 않으면 ‘새 버전이 나오면 알려
주기’를 끄세요. 끄면 여기에 새 버전도 나타나지 않아요.

업데이트할 때 나루는 파일마다 설치했을 때와 비교해요.

- 템플릿이 쓴 그대로인 파일은 새 버전으로 바뀌어요.
- 내가 고친 파일은 `/.backup/<시각>/`에 보관한 뒤 바뀌어요. 고친 내용은 남지만,
  다시 옮겨 와야 해요.
- 새 버전에 없는 파일은, 고쳤으면 남고 아니면 지워져요.
- 데이터베이스(테이블과 데이터)는 그대로예요.
- `/{{owner}}/` 폴더는 건드리지 않아요.

중간에 실패하면 파일을 원래대로 되돌리고 지금 버전에 그대로 머물러요.

## 04 · 예전 파일 찾기 {#backup}

적용이나 업데이트로 바뀐 파일은 [파일 편집기](/files)의 `/.backup/<시각>/` 폴더에
있어요. 필요한 내용을 찾아 옮겨 오세요. `/{{owner}}/` 폴더처럼 업데이트에 영향을 받지
않는 곳에 두면 다시 바뀌지 않아요.

## 05 · 연결 끊기 {#disconnect}

[설치한 템플릿](/templates/installed)에서 템플릿마다 연결을 끊을 수 있어요.

- **연결 끊기**: 파일은 그대로 내 것이 되고, 더는 새 버전을 받지 않아요.
- **템플릿 파일 지우고 연결 끊기**: 템플릿이 설치한 그대로인 파일을 `/.backup/`에
  보관하고 지워요. 내가 고친 파일은 남아요.

어느 쪽이든 데이터베이스는 그대로예요.
