쓰던 AI 앱에 나루를 추가하면, 그 앱에게 말로 부탁해서 내 홈페이지의 파일을
읽고, 만들고, 고칠 수 있어요. Claude에서는 커넥터로, ChatGPT에서는 플러그인으로
바로 추가할 수 있어요. 누구나 쓸 수 있고, 방명록이나 블로그처럼 데이터베이스를
쓰는 기능에는 서포터 플랜이 필요해요.

## 01 · 연결하기 {#connect}

1. 쓰는 앱에 나루를 추가하세요.
   - **Claude**: [디렉터리의 나루 커넥터](https://claude.ai/directory/naru)
   - **ChatGPT**: [나루 플러그인](https://chatgpt.com/plugins/plugin_asdk_app_6adb58fcd698819188aea50b247bfed4)
   - **다른 앱**: [다른 앱에서 연결하기](#other-apps)를 보세요.
2. 앱이 나루 로그인 화면을 열어요. 나루 계정으로 로그인하세요.
3. 연결할 앱의 이름과 돌아갈 주소를 확인하고, 허용할 일을 고른 뒤 ‘연결’을
   누르세요. 읽기만 허용하면 앱은 파일을 바꾸지 못해요. 데이터베이스 문서는 따로
   골라야 허용돼요.

## 02 · 이렇게 부탁해 보세요 {#ask}

연결한 뒤에는 앱과 대화하듯 부탁하면 돼요. ‘나루에서’라고 말해 주면
앱이 나루 연결을 써요. 어느 파일인지, 무엇을 바꾸고 싶은지 구체적으로
말할수록 좋아요.

> 나루에서 index.html 위쪽에 다른 페이지로 가는 메뉴를 달아 줘.

> 나루에서 diary 폴더에 오늘 날짜로 빈 일기 페이지를 하나 만들고, index.html에 링크를 달아 줘.

> 나루에서 내 홈페이지 파일들을 보고 깨진 링크가 있는지 찾아 줘.

> 나루에서 style.css의 색을 가을 느낌으로 바꿔 줘. 바꾸기 전에 무엇을 바꿀지 먼저 알려 줘.

> 나루에서 방문자가 인사를 남길 수 있는 방명록을 만들어 줘.

> 나루에서 글 목록과 글 페이지가 있는 블로그를 만들어 줘. 글은 내가 쓸게.

> 나루에서 방명록을 없애 줘.

앱이 파일을 저장하면 그 즉시 홈페이지에 공개돼요. 중요한 페이지는 바꾸기 전에
무엇을 바꿀지 먼저 보여 달라고 하세요. 앱이 고친 파일은
[파일 편집기](/files)에서도 바로 보이고, 거기서 다시 고칠 수 있어요.

## 03 · 앱이 할 수 있는 일 {#tools}

연결된 앱은 내 사이트 하나만 다뤄요. 계정 설정, 결제, 커스텀 도메인은 다룰 수
없어요. 무엇을 할 수 있는지는 연결할 때 허용한 일에 따라 달라요.

| 허용한 일    | 앱이 할 수 있는 일                                               |
| ------------ | ---------------------------------------------------------------- |
| 읽기         | 사이트 정보, 파일과 이미지, 컬렉션 설정 보기                     |
| 수정         | 파일과 폴더 만들기, 고치기, 옮기기, 지우기. 새 컬렉션 만들기     |
| 데이터베이스 | 방명록 글 같은 문서 읽기. 수정도 허용했다면 문서 고치기와 지우기 |

데이터베이스 컬렉션과 문서를 다루려면 서포터 플랜이 필요해요.
앱은 [웹 SDK 1.1.0](/docs/sdk/1.1.0) 사용법을 읽고 방명록이나 블로그처럼
데이터를 쓰는 페이지를 만들 수 있어요. 새 컬렉션은 바로 만들어지지만, 이미 있는
컬렉션의 공개 범위를 넓히는 변경은 [데이터베이스](/database)에서 내가 승인해야
반영돼요. 데이터베이스 문서에는 방문자가 쓴 글이 있어 앱이 그 글에 휘둘릴 수
있으니, 문서는 필요할 때만 허용하세요.

`_naru/collections.json`처럼 `_naru/` 폴더에 저장한 파일도 파일 편집기에서
저장할 때와 똑같이 적용돼요.

방명록 같은 기능을 없애 달라고 하면, 앱은 그 파일과 폴더를 지우고 다른
페이지에 남은 링크를 걷어 내요.
컬렉션과 그 안의 글은 앱이 지울 수 없어요. 필요 없으면
[데이터베이스](/database)에서 직접 지우세요. 지운 파일은 되돌릴 수 없으니,
무엇을 지울지 먼저 보여 달라고 하면 좋아요.

## 04 · 한도 {#limits}

- 파일 하나는 10 MB까지, [파일 편집기](/docs/files#limits)와 같은 형식만 올릴
  수 있어요.
- 앱이 내용을 읽을 수 있는 파일은 1 MB까지의 텍스트와 이미지예요. 그보다 큰
  파일은 주소만 알려 줘요.
- `index.html`은 지우거나 옮길 수 없어요.
- 계정마다 분당 60번까지 요청할 수 있어요. 서포터는 120번까지예요.
- 서포터가 아니면 앱으로 저장하는 양의 기준은 하루에 파일 300개와 100 MB, 사이트
  전체 1 GB예요. 넘어도 저장은 되고 앱이 알려 줘요. 기준의 10배를 넘으면 앱으로는
  더 저장할 수 없어요.

## 05 · 연결 끊기 {#disconnect}

[계정](/account)의 ‘AI 앱 연결’에서 앱마다 ‘연결 끊기’를 누르면 그 앱은 바로
사이트를 읽거나 고칠 수 없게 돼요. 30일 동안 쓰지 않은 연결은 다시 로그인해야 해요. 서포터
기간이 끝나면 연결은 그대로 남아 파일을 다룰 수 있지만, 다시 서포터가 될 때까지 데이터베이스는 다룰 수 없어요.

## 06 · 다른 앱에서 연결하기 {#other-apps}

Codex나 Claude Code처럼 커넥터나 플러그인으로 추가할 수 없는 앱도 MCP(Model
Context Protocol)를 지원하면 연결할 수 있어요. 앱의 MCP 서버 설정에 아래 주소를
넣으세요. 넣는 방법은 앱마다 달라요. [Claude Code](https://code.claude.com/docs/ko/mcp)는
이 안내를 보세요. 그다음은 [연결하기](#connect)의 로그인부터 똑같아요.

```
{{mcp_url}}
```

앱에게는 나루가 이런 도구로 보여요.

| 도구                    | 권한                | 하는 일                                             |
| ----------------------- | ------------------- | --------------------------------------------------- |
| `get_site`              | 읽기                | 사이트 주소, 제목, 마지막 수정 시각, 서포터 기간    |
| `list_files`            | 읽기                | 폴더 아래 파일과 크기, 수정 시각                    |
| `read_file`             | 읽기                | 텍스트 파일의 내용, 이미지                          |
| `write_file`            | 수정                | 파일을 만들거나 통째로 바꾸고 바로 공개             |
| `move_file`             | 수정                | 파일 옮기기, 이름 바꾸기                            |
| `delete_file`           | 수정                | 파일 지우기 (되돌릴 수 없음)                        |
| `delete_folder`         | 수정                | 폴더와 그 안의 파일 모두 지우기 (되돌릴 수 없음)    |
| `get_sdk_reference`     | 누구나              | 웹 SDK 1.1.0 사용법과 레퍼런스                      |
| `list_collections`      | 읽기                | 컬렉션과 읽기·쓰기 공개 범위                        |
| `configure_collections` | 수정                | 컬렉션 만들기 (공개 범위를 넓히는 변경은 내가 승인) |
| `list_documents`        | 데이터베이스        | 컬렉션의 문서 목록, 필터와 정렬                     |
| `get_document`          | 데이터베이스        | 문서 하나                                           |
| `set_document`          | 데이터베이스 + 수정 | 문서를 만들거나 통째로 바꾸고 바로 반영             |
| `delete_document`       | 데이터베이스 + 수정 | 문서 지우기 (되돌릴 수 없음)                        |
