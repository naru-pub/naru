나루 홈페이지는 HTML, CSS, 이미지 같은 파일로 만들어져요. 상단의 ‘직접 만들기’에서
그 파일들을 브라우저 안에서 바로 만들고 고칠 수 있어요. 저장하면 바로
홈페이지에 나타나요.

## 01 · 첫 페이지 고치기 {#start}

1. 로그인하고 상단의 [직접 만들기](/files)를 누르세요. 왼쪽에 내 홈페이지의 파일과
   폴더가 나와요.
2. `index.html`을 누르세요. 홈페이지 주소(`아이디.naru.pub`)로 들어온 사람이
   처음 보는 페이지예요.
3. 가운데 편집기에서 글자를 고치고 ‘저장’을 누르세요. 홈페이지를 새로고침하면
   고친 내용이 보여요.

다른 페이지는 파일 이름이 곧 주소예요. `about.html`은
`아이디.naru.pub/about.html`에, `diary/first.html`은
`아이디.naru.pub/diary/first.html`에 있어요.

## 02 · 파일과 폴더 만들기 {#create}

왼쪽 파일 목록 위의 ‘파일’, ‘폴더’ 버튼을 누르고 이름을 쓴 뒤 <kbd>Enter</kbd>를
누르세요. 버튼 위에 보이는 `$ cd ~/폴더`가 새로 생길 곳이에요. 목록에서 폴더를
고르면 그 안에 생겨요. 파일이나 폴더를 마우스 오른쪽 버튼으로 눌러 ‘새 파일’,
‘새 폴더’를 골라도 돼요.

- 파일 이름에는 `.html`, `.css`처럼 확장자를 꼭 붙이세요. 확장자로 파일의
  종류가 정해져요.
- 새 `.html` 파일은 빈 파일이 아니라 페이지의 기본 뼈대가 들어간 채로
  만들어져요. `<body>`와 `</body>` 사이에 내용을 쓰면 돼요.

## 03 · 이미지와 파일 올리기 {#upload}

왼쪽 위의 ‘업로드’ 버튼을 누르거나, 내 컴퓨터의 파일을 편집기 화면으로 끌어다
놓으세요. 여러 개를 한 번에 올릴 수 있어요. 파일은 왼쪽에서 고른 폴더에
들어가요. 아무것도 고르지 않았다면 맨 위 폴더에 들어가요.

올린 이미지는 페이지에서 경로로 불러요. `images` 폴더에 `cat.png`를 올렸다면
이렇게 써요.

```html
<img src="images/cat.png" alt="우리 집 고양이" />
```

같은 이름의 파일이 이미 있으면 새로 올린 파일로 바뀌어요. 이미지는 파일을
누르면 편집기 자리에서 보이고, ‘축소’, ‘원본’, ‘확대’로 크기를 바꿔 볼 수
있어요.

## 04 · 고치고 저장하기 {#edit}

- 파일을 누르면 위쪽에 탭으로 열려요. 여러 파일을 열어 두고 탭을 눌러 오갈 수
  있어요.
- 고치고 아직 저장하지 않은 파일은 탭에 ‘저장하지 않음’ 표시가 붙어요. ‘저장’
  버튼이나 <kbd>Ctrl</kbd> <kbd>S</kbd>(맥은 <kbd>⌘</kbd> <kbd>S</kbd>)로
  저장하세요. 저장하지 않고 탭을 닫으려 하면 한 번 더 물어봐요.
- 저장하기 전에 ‘변경 사항’을 누르면 저장된 내용과 무엇이 달라졌는지 나란히 볼
  수 있어요. ‘편집’을 누르면 돌아와요.
- ‘포맷’은 들여쓰기와 줄바꿈을 보기 좋게 정리해요. 톱니바퀴 모양의 편집기
  설정에서 ‘저장할 때 포맷’, ‘자동 줄바꿈’, ‘미니맵’을 켜고 끌 수 있어요.
- 파일을 연 뒤에 다른 탭이나 MCP로 연결한 앱에서 같은 파일이 저장되었다면,
  저장할 때 알려 줘요. 덮어쓰거나, 저장된 버전을 불러오거나, 저장하지 않고 둘 수
  있어요.

## 05 · 미리보기 {#preview}

HTML 파일을 연 채로 ‘미리보기’를 누르면 편집기 옆에 그 페이지가 홈페이지에
보이는 모습 그대로 나와요. 저장할 때마다 다시 불러오니, CSS나 이미지를 바꾼
것도 바로 확인할 수 있어요. 새 탭에서 크게 보려면 미리보기 위의 열기 버튼을
누르세요.

미리보기는 저장된 파일을 보여 줘요. 고친 내용이 안 보이면 먼저 저장하세요.

## 06 · 이름 바꾸기, 옮기기, 지우기 {#organize}

- **이름 바꾸기**: 파일을 오른쪽 버튼으로 눌러 ‘이름 변경’을 고르거나, 고른 뒤
  <kbd>F2</kbd>를 누르세요. 편집기 위에 보이는 파일 이름을 두 번 눌러도 돼요.
  같은 이름이 이미 있으면 덮어쓸지 물어봐요.
- **옮기기**: 파일을 끌어다 왼쪽 목록의 다른 폴더 위에 놓으세요.
- **지우기**: 오른쪽 버튼 메뉴에서 ‘삭제’를 고르세요. 폴더를 지우면 안의
  파일도 모두 지워지고, 지우기 전에 어떤 파일이 함께 지워지는지 보여 줘요. 지운
  파일은 되돌릴 수 없어요.
- `index.html`은 홈페이지의 첫 페이지라 이름을 바꾸거나 지울 수 없어요.

오른쪽 버튼 메뉴의 ‘새 탭에서 열기’를 고르면 그 파일을 홈페이지 주소로 열어요.
주소를 다른 사람에게 알려 줄 때 쓰세요.

## 07 · 단축키 {#keys}

맥에서는 Ctrl 대신 ⌘(Command)를 누르세요.

| 키                                               | 하는 일                 |
| ------------------------------------------------ | ----------------------- |
| <kbd>Ctrl</kbd> + <kbd>S</kbd>                   | 저장                    |
| <kbd>Ctrl</kbd> + <kbd>P</kbd>                   | 파일 이름으로 찾아 열기 |
| <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>F</kbd> | 보기 좋게 정리(포맷)    |
| <kbd>F2</kbd>                                    | 고른 파일 이름 바꾸기   |

## 08 · 한도 {#limits}

- 파일 하나는 10 MB까지 올릴 수 있어요. 빈 파일은 올릴 수 없어요.
- 올릴 수 있는 형식은 다음과 같아요: {{extensions}}.
- 파일 이름은 255자까지이고, `/`는 쓸 수 없어요. 폴더는 ‘폴더’ 버튼으로
  만드세요.
